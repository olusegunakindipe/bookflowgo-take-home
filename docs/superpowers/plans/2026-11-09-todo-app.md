# ToDo App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single-user ToDo app: an Express + SQLite API in `server/` and a React + Tailwind UI in `web/`, connected through the Vite dev proxy. It meets the take-home brief with server-authoritative validation and tests on both sides.

**Architecture:**
- The server is layered: routes → service → repository. `createApp(repo)` takes its dependencies as a parameter, so API tests run against a `:memory:` SQLite database.
- The web app keeps all state in one `useTodos` hook (`useReducer`), does all I/O in one `todosApi` module, and keeps validation in a pure function. Components only render and raise events.
- The UI applies a change only after the server confirms it. There are no optimistic updates.

**Tech Stack:**
- Node 20.19, TypeScript 5.
- **Server:** Express 5, better-sqlite3, Zod 4, helmet. Tests: Vitest 4, Supertest.
- **Web:** Vite 6, React 18, Tailwind CSS 4. Tests: Vitest 4, React Testing Library, jsdom.

**Spec:** `docs/superpowers/specs/2026-11-09-todo-app-design.md`. Read it before starting. This plan implements it and does not repeat its rationale.

## Global Constraints

- The runtime is Node `v20.19.x`. Every package must support Node 20.
- Folders: `server/` for the backend and `web/` for the frontend. There are no root workspaces.
- Field limits: title is 1–200 characters after trimming; description is at most 2000 characters after trimming. Both are counted in UTF-16 code units (`.length`).
- `dueAt` is an ISO 8601 date-time **with an offset**. It is stored and returned in UTC as `toISOString()`, or as `null`.
- `ordinal` = `max(ordinal) + 1`, or `1` when the table is empty. Only the server assigns it.
- The error body is always `{ "error": { "code", "message", "details?" } }`. Codes: `VALIDATION_ERROR` 400, `INVALID_JSON` 400, `UNSUPPORTED_MEDIA_TYPE` 415, `PAYLOAD_TOO_LARGE` 413, `NOT_FOUND` 404, `INTERNAL_ERROR` 500.
- The JSON body limit is `10kb`. The server binds to `127.0.0.1:3001` by default.
- Web request timeout: 10 000 ms. Retries are manual only.
- UI copy, exactly:
  - Network failure: `Can't reach the server. Check it's running and try again.`
  - Server failure: `Something went wrong on the server. Your changes weren't saved. Please try again.`
  - Not found: `This todo no longer exists.`
- Do not add: rate limiting, auth, pagination, `createdAt`/`updatedAt`, overdue badges, dark mode, animations, or a state library.

## Spec amendments made by this plan (needs developer approval)

1. **No `maxLength` on the title and description inputs.** The spec said inputs carry `maxLength`. However, `maxLength` silently truncates pasted text, and it makes the "over-length input shows an inline error" behaviour unreachable, even though the developer explicitly asked for that check. Instead, the description shows a live `n/2000` counter, and any over-length field gets an inline error on submit without sending a request.
2. **Web tests stub `fetch` itself** (`vi.stubGlobal`) rather than mocking the `todosApi` module. This exercises `todosApi`'s error parsing and timeout in every flow test.

Both amendments are applied to the spec in the same commit as this plan.

## Plan revisions

- **Task 4 review (endpoints):** `GET /api/todos/:id` was removed, along with `TodoService.get`, `TodoRepository.findById` and the `Location` header, because neither the brief nor the UI needs them. Code snippets in the completed Tasks 1–4 still show the original version; the committed code and the spec are authoritative, and the interface lines above are updated for later tasks.
- **Task 3 review (typecheck gap), applied in Task 4:** `npm run typecheck` skipped test files because `tsconfig.json` excluded them. The config is now split: `tsconfig.json` type-checks `src` and `test` and never emits, while `tsconfig.build.json` emits `src` only.
- **Task 4 (probe):** `"text"` and `null` bodies are valid JSON but rejected by Express's strict parser with `INVALID_JSON`, and the old message ("not valid JSON") was misleading. It is now "Request body must be a valid JSON object".
- **Task 3 review (transactions):** the transaction around create was removed. The ordinal is computed inside a single `INSERT … SELECT`, so every write is one atomic statement.
- **Task 1 (dependency audit):** the originally pinned zod 3.25 had a high-severity runtime advisory (GHSA-mrhx-c7xc-m3w5), and vitest 3.2 had critical and moderate dev-only advisories. The developer chose to upgrade to zod ^4.6.7 and vitest ^4.1.12 before any code was written. Task 2's schemas use Zod 4 syntax (`z.strictObject`, `z.iso.datetime`, `error`), and the behaviour was verified by probe before the rewrite.

## Review Focus

These are the inputs most likely to break the app for a real user that the main tests would not otherwise cover. Each one has a test added in the task that owns the code.

1. **An impossible calendar date** (`2026-02-30T10:00:00Z`) must give `400`, not be silently rolled over to March. *Task 2*
2. **A whitespace-only title on PATCH** (`{"title":"   "}`) must give `400`, so an edit cannot blank a title that is required on create. *Task 2*
3. **A repeated query parameter** (`?includeCompleted=true&includeCompleted=false`) becomes an array in Express and must give `400`, not `500`. *Task 4*
4. **Valid JSON that is not an object** (`[]`, `"text"`, `null`) must give `400`, not `500`. *Task 4*
5. **Rapidly toggling "Show completed"** must never let a slow, stale list response overwrite the newer one. *Task 7*

```ts
import Database from 'better-sqlite3';
import { mkdirSync } from 'node:fs';
import { dirname } from 'node:path';

export type Db = Database.Database;

const SCHEMA = `
  CREATE TABLE IF NOT EXISTS todos (
    id          TEXT PRIMARY KEY,
    title       TEXT NOT NULL,
    description TEXT NOT NULL DEFAULT '',
    due_at      TEXT NULL,
    ordinal     INTEGER NOT NULL UNIQUE,
    completed   INTEGER NOT NULL DEFAULT 0 CHECK (completed IN (0, 1))
  );
  CREATE INDEX IF NOT EXISTS idx_todos_completed_ordinal ON todos (completed, ordinal);
`;

/** Opens (creating if needed) the SQLite database and applies the idempotent schema. */
export function openDatabase(path: string): Db {
  if (path !== ':memory:') mkdirSync(dirname(path), { recursive: true });
  const db = new Database(path);
  db.exec(SCHEMA);
  return db;
}
```

`server/src/todos/todo.repository.ts`:
```ts
import { randomUUID } from 'node:crypto';
import type { Db } from '../db/database';

export interface Todo {
  id: string;
  title: string;
  description: string;
  dueAt: string | null;
  ordinal: number;
  completed: boolean;
}

export interface NewTodo {
  title: string;
  description: string;
  dueAt: string | null;
}

export type TodoChanges = Partial<Pick<Todo, 'title' | 'description' | 'dueAt' | 'completed'>>;

/** Persistence port: the service depends on this, not on SQLite. */
export interface TodoRepository {
  list(opts: { includeCompleted: boolean }): Todo[];
  findById(id: string): Todo | undefined;
  create(input: NewTodo): Todo;
  update(id: string, changes: TodoChanges): Todo | undefined;
  delete(id: string): boolean;
}

interface TodoRow {
  id: string;
  title: string;
  description: string;
  due_at: string | null;
  ordinal: number;
  completed: 0 | 1;
}

/** Explicit mapper: responses never expose raw rows. */
function toTodo(row: TodoRow): Todo {
  return {
    id: row.id,
    title: row.title,
    description: row.description,
    dueAt: row.due_at,
    ordinal: row.ordinal,
    completed: row.completed === 1,
  };
}

export function createSqliteTodoRepository(db: Db): TodoRepository {
  const listOpen = db.prepare('SELECT * FROM todos WHERE completed = 0 ORDER BY ordinal');
  const listAll = db.prepare('SELECT * FROM todos ORDER BY ordinal');
  const byId = db.prepare('SELECT * FROM todos WHERE id = ?');
  // Every write below is a single statement, which SQLite runs atomically, so no explicit
  // transactions are needed. The ordinal (max + 1) is computed inside the INSERT itself.
  const insert = db.prepare(`
    INSERT INTO todos (id, title, description, due_at, ordinal, completed)
    VALUES (@id, @title, @description, @dueAt, (SELECT COALESCE(MAX(ordinal), 0) + 1 FROM todos), 0)
    RETURNING *`);
  const update = db.prepare(`
    UPDATE todos SET
      title       = COALESCE(@title, title),
      description = COALESCE(@description, description),
      due_at      = CASE WHEN @setDueAt = 1 THEN @dueAt ELSE due_at END,
      completed   = COALESCE(@completed, completed)
    WHERE id = @id
    RETURNING *`);
  const remove = db.prepare('DELETE FROM todos WHERE id = ?');

  return {
    list: ({ includeCompleted }) =>
      ((includeCompleted ? listAll : listOpen).all() as TodoRow[]).map(toTodo),
    findById: (id) => {
      const row = byId.get(id) as TodoRow | undefined;
      return row && toTodo(row);
    },
    create: (input) => toTodo(insert.get({ id: randomUUID(), ...input }) as TodoRow),
    update: (id, changes) => {
      const row = update.get({
        id,
        title: changes.title ?? null,
        description: changes.description ?? null,
        setDueAt: changes.dueAt === undefined ? 0 : 1,
        dueAt: changes.dueAt ?? null,
        completed: changes.completed === undefined ? null : changes.completed ? 1 : 0,
      }) as TodoRow | undefined;
      return row && toTodo(row);
    },
    delete: (id) => remove.run(id).changes > 0,
  };
}
```

```ts
export class AppError extends Error {
```

```ts
  description: description.optional(),
  dueAt: dueAt.optional(),

    title: title.optional(),
    description: description.optional(),

export type UpdateTodoInput = z.infer<typeof updateTodoSchema>;

    issue.code === 'unrecognized_keys'
```

```ts
import { NotFoundError } from '../http/errors';
import type { Todo, TodoChanges, TodoRepository } from './todo.repository';
import type { CreateTodoInput, UpdateTodoInput } from './todo.schema';

/** Accepts a validated ISO date-time with an offset and returns it in canonical UTC form. */
export function toUtcIso(value: string | null): string | null {
  return value === null ? null : new Date(value).toISOString();
}

/** Domain rules: defaults, UTC normalisation, not-found. Depends only on the TodoRepository port. */
export class TodoService {
  constructor(private readonly repo: TodoRepository) {}

  list(includeCompleted: boolean): Todo[] {
    return this.repo.list({ includeCompleted });
  }

  get(id: string): Todo {
    const todo = this.repo.findById(id);
    if (!todo) throw new NotFoundError();
    return todo;
  }

  create(input: CreateTodoInput): Todo {
    return this.repo.create({
      title: input.title,
      description: input.description ?? '',
      dueAt: toUtcIso(input.dueAt ?? null),
    });
  }

  update(id: string, input: UpdateTodoInput): Todo {
    const changes: TodoChanges = { ...input };
    if (input.dueAt !== undefined) changes.dueAt = toUtcIso(input.dueAt);
    const todo = this.repo.update(id, changes);
    if (!todo) throw new NotFoundError();
    return todo;
  }

  delete(id: string): void {
    if (!this.repo.delete(id)) throw new NotFoundError();
  }
}
```

```ts
import type { ErrorRequestHandler, RequestHandler } from 'express';
import {
  AppError,
  InternalError,
  InvalidJsonError,
  NotFoundError,
  PayloadTooLargeError,
  UnsupportedMediaTypeError,
} from './errors';

const BODY_METHODS = new Set(['POST', 'PUT', 'PATCH']);

/** Requests that carry a body must declare JSON; anything else gets a 415. */
export const requireJsonBody: RequestHandler = (req, _res, next) => {
  if (BODY_METHODS.has(req.method) && !req.is('application/json')) {
    next(new UnsupportedMediaTypeError());
    return;
  }
  next();
};

export const notFoundHandler: RequestHandler = (_req, _res, next) => {
  next(new NotFoundError('Route not found'));
};

/** Converts body-parser failures to AppErrors; anything unknown becomes a generic 500. */
function toAppError(err: unknown): AppError {
  if (err instanceof AppError) return err;
  const type = (err as { type?: unknown } | null)?.type;
  if (type === 'entity.parse.failed') return new InvalidJsonError();
  if (type === 'entity.too.large') return new PayloadTooLargeError();
  return new InternalError();
}

/** The single place where errors become HTTP responses. Internals are logged, never sent. */
export const errorHandler: ErrorRequestHandler = (err, _req, res, _next) => {
  const appError = toAppError(err);
  if (appError.status >= 500) console.error(err);
  res.status(appError.status).json({
    error: {
      code: appError.code,
      message: appError.message,
      ...(appError.details && { details: appError.details }),
    },
  });
};
```

```ts
import { Router } from 'express';
import type { z } from 'zod';
import { NotFoundError, ValidationError } from '../http/errors';
import { createTodoSchema, idSchema, listQuerySchema, toFieldErrors, updateTodoSchema } from './todo.schema';
import type { TodoService } from './todo.service';

function parse<S extends z.ZodType>(schema: S, data: unknown): z.output<S> {
  const result = schema.safeParse(data);
  if (!result.success) throw new ValidationError(toFieldErrors(result.error));
  return result.data;
}

/** A malformed id can never match a todo, so it gets a 404 rather than a 400. */
function parseId(raw: string): string {
  if (!idSchema.safeParse(raw).success) throw new NotFoundError();
  return raw;
}

/** HTTP adapter: parses input, calls the service, chooses the status code. No domain rules here. */
export function todoRouter(service: TodoService): Router {
  const router = Router();

  router.get('/', (req, res) => {
    const { includeCompleted } = parse(listQuerySchema, req.query);
    res.json(service.list(includeCompleted));
  });

  router.get('/:id', (req, res) => {
    res.json(service.get(parseId(req.params.id)));
  });

  router.post('/', (req, res) => {
    const todo = service.create(parse(createTodoSchema, req.body));
    res.status(201).location(`/api/todos/${todo.id}`).json(todo);
  });

  router.patch('/:id', (req, res) => {
    const id = parseId(req.params.id);
    res.json(service.update(id, parse(updateTodoSchema, req.body)));
  });

  router.delete('/:id', (req, res) => {
    service.delete(parseId(req.params.id));
    res.status(204).end();
  });

  return router;
}
```

```ts
export interface Config {
  host: string;
  port: number;
  dbPath: string;
}

export function loadConfig(env: NodeJS.ProcessEnv = process.env): Config {
  const port = Number(env.PORT ?? 3001);
  if (!Number.isInteger(port) || port < 1 || port > 65535) {
    throw new Error(`Invalid PORT: ${env.PORT}`);
  }
  return {
    host: env.HOST ?? '127.0.0.1', // no auth, so do not listen on the network by default
    port,
    dbPath: env.DB_PATH ?? 'data/todos.db',
  };
}
```

```ts
import { ApiError, type CreateTodoInput, type FieldError, type Todo, type UpdateTodoInput } from './types';

export const REQUEST_TIMEOUT_MS = 10_000;

export const MESSAGES = {
  network: "Can't reach the server. Check it's running and try again.",
  server: "Something went wrong on the server. Your changes weren't saved. Please try again.",
  notFound: 'This todo no longer exists.',
  validation: 'Please fix the highlighted fields.',
  unknown: 'The request could not be completed. Please try again.',
} as const;

interface ErrorBody {
  error?: { code?: string; message?: string; details?: FieldError[] };
}

async function toApiError(response: Response): Promise<ApiError> {
  const body = (await response.json().catch(() => null)) as ErrorBody | null;
  const { status } = response;
  if (status === 400 && body?.error?.code === 'VALIDATION_ERROR') {
    return new ApiError('validation', MESSAGES.validation, status, body.error.details ?? []);
  }
  if (status === 404) return new ApiError('not_found', MESSAGES.notFound, status);
  if (status >= 500) return new ApiError('server', MESSAGES.server, status);
  return new ApiError('other', body?.error?.message ?? MESSAGES.unknown, status);
}

/** The only place that talks to the network. Every failure becomes an ApiError. */
async function request<T>(url: string, init: RequestInit = {}): Promise<T> {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), REQUEST_TIMEOUT_MS);
  let response: Response;
  try {
    response = await fetch(url, { ...init, signal: controller.signal });
  } catch {
    throw new ApiError('network', MESSAGES.network); // server down, offline, or timed out
  } finally {
    clearTimeout(timer);
  }
  if (!response.ok) throw await toApiError(response);
  return (response.status === 204 ? undefined : await response.json()) as T;
}

const withJson = (method: string, body: unknown): RequestInit => ({
  method,
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(body),
});

const itemUrl = (id: string) => `/api/todos/${encodeURIComponent(id)}`;

export const listTodos = (includeCompleted: boolean) =>
  request<Todo[]>(`/api/todos?includeCompleted=${includeCompleted}`, { method: 'GET' });

export const createTodo = (input: CreateTodoInput) => request<Todo>('/api/todos', withJson('POST', input));

export const updateTodo = (id: string, changes: UpdateTodoInput) =>
  request<Todo>(itemUrl(id), withJson('PATCH', changes));

export const deleteTodo = (id: string) => request<void>(itemUrl(id), { method: 'DELETE' });
```

`web/src/validation/todoForm.ts`:
```ts
import type { FieldError } from '../api/types';

// Must match the server (spec §2). Both sides count UTF-16 code units via .length.
export const TITLE_MAX = 200;
export const DESCRIPTION_MAX = 2000;

export interface TodoFormValues {
  title: string;
  description: string;
  dueAt: string; // value of <input type="datetime-local">, or ''
}

export type TodoFormErrors = Partial<Record<'title' | 'description' | 'dueAt' | 'form', string>>;

/** Instant UX feedback only; the server remains the authority. */
export function validateTodoForm(values: TodoFormValues): TodoFormErrors {
  const errors: TodoFormErrors = {};
  const title = values.title.trim();
  if (!title) errors.title = 'Title is required';
  else if (title.length > TITLE_MAX) errors.title = `Title must be at most ${TITLE_MAX} characters`;

  if (values.description.trim().length > DESCRIPTION_MAX) {
    errors.description = `Description must be at most ${DESCRIPTION_MAX} characters`;
  }
  if (values.dueAt && Number.isNaN(new Date(values.dueAt).getTime())) {
    errors.dueAt = 'Enter a valid due date';
  }
  return errors;
}

/** datetime-local values have no offset and are read as the browser's local time, then sent as UTC. */
export function toUtcIso(local: string): string | null {
  return local ? new Date(local).toISOString() : null;
}

/** UTC ISO → "YYYY-MM-DDTHH:mm" in local time, for pre-filling the edit form. */
export function toLocalInput(iso: string | null): string {
  if (!iso) return '';
  const d = new Date(iso);
  const pad = (n: number) => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}T${pad(d.getHours())}:${pad(d.getMinutes())}`;
}

/** Puts server field errors on the matching inputs; anything unexpected becomes a form-level message. */
export function mapServerErrors(fieldErrors: FieldError[]): TodoFormErrors {
  const errors: TodoFormErrors = {};
  for (const { field, message } of fieldErrors) {
    const key = field === 'title' || field === 'description' || field === 'dueAt' ? field : 'form';
    errors[key] ??= message;
  }
  return errors;
}
```

```ts
import { useCallback, useEffect, useReducer } from 'react';
import * as api from '../api/todosApi';
import { ApiError, type FieldError, type Todo } from '../api/types';

export interface TodoDraft {
  title: string;
  description: string;
  dueAt: string | null;
}

export type MutationResult = { ok: true } | { ok: false; fieldErrors: FieldError[] };

export interface TodosState {
  items: Todo[];
  includeCompleted: boolean;
  status: 'loading' | 'ready' | 'error';
  loadError: string | null;
  actionError: string | null;
  reloadKey: number;
}

export type TodosAction =
  | { type: 'load_start' }
  | { type: 'load_success'; items: Todo[] }
  | { type: 'load_failure'; message: string }
  | { type: 'set_include_completed'; value: boolean }
  | { type: 'reload' }
  | { type: 'upsert'; todo: Todo }
  | { type: 'remove'; id: string }
  | { type: 'action_error'; message: string }
  | { type: 'dismiss_error' };

export const initialState: TodosState = {
  items: [],
  includeCompleted: false,
  status: 'loading',
  loadError: null,
  actionError: null,
  reloadKey: 0,
};

export function todosReducer(state: TodosState, action: TodosAction): TodosState {
  switch (action.type) {
    case 'load_start':
      return { ...state, status: 'loading', loadError: null };
    case 'load_success':
      return { ...state, status: 'ready', items: action.items };
    case 'load_failure':
      return { ...state, status: 'error', loadError: action.message };
    case 'set_include_completed':
      return { ...state, includeCompleted: action.value };
    case 'reload':
      return { ...state, reloadKey: state.reloadKey + 1 };
    case 'upsert': {
      const others = state.items.filter((t) => t.id !== action.todo.id);
      const visible = state.includeCompleted || !action.todo.completed;
      const items = visible ? [...others, action.todo].sort((a, b) => a.ordinal - b.ordinal) : others;
      return { ...state, items, actionError: null };
    }
    case 'remove':
      return { ...state, items: state.items.filter((t) => t.id !== action.id), actionError: null };
    case 'action_error':
      return { ...state, actionError: action.message };
    case 'dismiss_error':
      return { ...state, actionError: null };
  }
}

const FALLBACK_MESSAGE = 'Something went wrong. Please try again.';

/** Owns all list state. Changes are applied only after the server confirms them (no optimistic updates). */
export function useTodos() {
  const [state, dispatch] = useReducer(todosReducer, initialState);

  useEffect(() => {
    let stale = false; // ignore responses for a superseded request (Review Focus #5)
    dispatch({ type: 'load_start' });
    api.listTodos(state.includeCompleted).then(
      (items) => !stale && dispatch({ type: 'load_success', items }),
      // A read failure must not say "your changes weren't saved", so only the network message is reused.
      (err) => !stale && dispatch({
        type: 'load_failure',
        message: err instanceof ApiError && err.kind === 'network' ? err.message : 'The server returned an error.',
      }),
    );
    return () => {
      stale = true;
    };
  }, [state.includeCompleted, state.reloadKey]);

  /** Field-level 400s go back to the form; every other failure shows the banner. A 404 also reloads. */
  const fail = useCallback((err: unknown): MutationResult => {
    if (err instanceof ApiError && err.kind === 'validation' && err.fieldErrors.length > 0) {
      return { ok: false, fieldErrors: err.fieldErrors };
    }
    dispatch({ type: 'action_error', message: err instanceof ApiError ? err.message : FALLBACK_MESSAGE });
    if (err instanceof ApiError && err.kind === 'not_found') dispatch({ type: 'reload' });
    return { ok: false, fieldErrors: [] };
  }, []);

  const saved = useCallback(async (request: Promise<Todo>): Promise<MutationResult> => {
    try {
      dispatch({ type: 'upsert', todo: await request });
      return { ok: true };
    } catch (err) {
      return fail(err);
    }
  }, [fail]);

  const createTodo = useCallback((draft: TodoDraft) => saved(api.createTodo(draft)), [saved]);
  const updateTodo = useCallback((id: string, draft: TodoDraft) => saved(api.updateTodo(id, draft)), [saved]);
  const toggleTodo = useCallback((todo: Todo) => saved(api.updateTodo(todo.id, { completed: !todo.completed })), [saved]);

  const deleteTodo = useCallback(async (id: string): Promise<MutationResult> => {
    try {
      await api.deleteTodo(id);
      dispatch({ type: 'remove', id });
      return { ok: true };
    } catch (err) {
      return fail(err);
    }
  }, [fail]);

  const setIncludeCompleted = useCallback((value: boolean) => dispatch({ type: 'set_include_completed', value }), []);
  const reload = useCallback(() => dispatch({ type: 'reload' }), []);
  const dismissError = useCallback(() => dispatch({ type: 'dismiss_error' }), []);

  return { ...state, createTodo, updateTodo, toggleTodo, deleteTodo, setIncludeCompleted, reload, dismissError };
}
```

```tsx
  type TodoFormErrors,
  type TodoFormValues,
} from '../validation/todoForm';

  initial?: Todo;
  submitLabel: string;

const inputClass =
  'w-full rounded-lg border border-slate-300 bg-white px-3 py-2 text-sm focus:border-indigo-500 focus:outline-none focus:ring-2 focus:ring-indigo-200 aria-[invalid=true]:border-red-500';

/** Shared by create and edit. Validates locally first, then shows any server field errors inline. */
export function TodoForm({ initial, submitLabel, onSubmit, onCancel }: TodoFormProps) {
  const id = useId();
  const [values, setValues] = useState<TodoFormValues>(
    initial ? { title: initial.title, description: initial.description, dueAt: toLocalInput(initial.dueAt) } : EMPTY,
  );
  const [errors, setErrors] = useState<TodoFormErrors>({});
  const [submitting, setSubmitting] = useState(false);

  const update = (field: keyof TodoFormValues) => (e: ChangeEvent<HTMLInputElement | HTMLTextAreaElement>) =>
    setValues((v) => ({ ...v, [field]: e.target.value }));

  async function handleSubmit(e: FormEvent) {
    e.preventDefault();
    const found = validateTodoForm(values);
    setErrors(found);
    if (Object.keys(found).length > 0) return;

    setSubmitting(true);
    const result = await onSubmit({
      title: values.title.trim(),
      description: values.description.trim(),
      dueAt: toUtcIso(values.dueAt),
    });
    setSubmitting(false);
    if (result.ok) {
      if (!initial) setValues(EMPTY);
    } else {
      setErrors(mapServerErrors(result.fieldErrors)); // input is kept on any failure
    }
  }

  const descriptionLength = values.description.length;

  return (
    <form onSubmit={handleSubmit} noValidate className="space-y-3">

          id={`${id}-title`}
          value={values.title}
          onChange={update('title')}
          aria-invalid={Boolean(errors.title)}
          aria-describedby={errors.title ? `${id}-title-error` : undefined}
          className={inputClass}
        />
        {errors.title && <p id={`${id}-title-error`} className="mt-1 text-xs text-red-600">{errors.title}</p>}

          onChange={update('description')}
          aria-invalid={Boolean(errors.description)}
          aria-describedby={`${id}-description-count${errors.description ? ` ${id}-description-error` : ''}`}
          className={inputClass}
        />
        <div className="mt-1 flex justify-between gap-2 text-xs">
          <span id={`${id}-description-error`} className="text-red-600">{errors.description}</span>
          <span
            id={`${id}-description-count`}
            className={descriptionLength > DESCRIPTION_MAX ? 'font-medium text-red-600' : 'text-slate-500'}

            Cancel

      </div>

  );
```

```tsx
import type { Todo } from '../api/types';
import type { MutationResult, TodoDraft } from '../hooks/useTodos';
import { TodoForm } from './TodoForm';

export interface TodoItemProps {
  todo: Todo;
  onToggle: (todo: Todo) => Promise<MutationResult>;
  onUpdate: (id: string, draft: TodoDraft) => Promise<MutationResult>;
  onDelete: (id: string) => Promise<MutationResult>;
}

const formatDue = (iso: string) =>
  new Date(iso).toLocaleString(undefined, { dateStyle: 'medium', timeStyle: 'short' });

const cardClass = 'flex h-full flex-col rounded-xl border border-slate-200 bg-white p-4 shadow-sm';
const smallButton =
  'rounded-md px-2 py-1 text-xs font-medium focus:outline-none focus-visible:ring-2 focus-visible:ring-indigo-400 disabled:opacity-50';

export function TodoItem({ todo, onToggle, onUpdate, onDelete }: TodoItemProps) {
  const [editing, setEditing] = useState(false);
  const [busy, setBusy] = useState(false);

  async function run(action: () => Promise<unknown>) {
    setBusy(true);
    try {
      await action();
    } finally {
      setBusy(false);
    }
  }

  if (editing) {
    return (
      <li className={cardClass}>
        <TodoForm
          initial={todo}
          submitLabel="Save"
          onCancel={() => setEditing(false)}
          onSubmit={async (draft) => {
            const result = await onUpdate(todo.id, draft);
            if (result.ok) setEditing(false);
            return result;
          }}
        />
      </li>
    );
  }

  return (
    <li className={cardClass}>
      <div className="flex items-start gap-3">
        <input
          type="checkbox"
          checked={todo.completed}
          disabled={busy}
          onChange={() => run(() => onToggle(todo))}
          aria-label={`Mark "${todo.title}" as ${todo.completed ? 'incomplete' : 'complete'}`}
          className="mt-1 h-4 w-4 shrink-0 accent-indigo-600"
        />
        <h3 className={`min-w-0 break-words font-medium ${todo.completed ? 'text-slate-400 line-through' : 'text-slate-900'}`}>
          {todo.title}
        </h3>
      </div>
      {todo.description && (
        <p className="mt-2 whitespace-pre-wrap break-words text-sm text-slate-600">{todo.description}</p>
      )}
      <div className="mt-auto flex items-center justify-between gap-2 pt-4">
        <span className="text-xs text-slate-500">{todo.dueAt ? `Due ${formatDue(todo.dueAt)}` : 'No due date'}</span>
        <div className="flex gap-1">
          <button
            type="button"
            disabled={busy}
            onClick={() => setEditing(true)}
            aria-label={`Edit "${todo.title}"`}
            className={`${smallButton} text-indigo-700 hover:bg-indigo-50`}
          >
            Edit
          </button>
          <button
            type="button"
            disabled={busy}
            onClick={() => window.confirm(`Delete "${todo.title}"?`) && run(() => onDelete(todo.id))}
            aria-label={`Delete "${todo.title}"`}
            className={`${smallButton} text-red-700 hover:bg-red-50`}
          >
            Delete
          </button>
        </div>
      </div>
    </li>
  );
}
```
